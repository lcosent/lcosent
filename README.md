### Luca Cosentino

Operator. Payments, product and applied AI. New York.

Small tools I build to think through hard problems in money movement, compliance and AI. Code is intentionally simple; the value is in the framing.

---

**Trust and compliance, rebuilt with AI**

- [`kyc-validator`](https://github.com/lcosent/experiments-public/tree/main/kyc-validator) — Local-only KYC document validator. LLM extraction and sanctions screening, all on-device. PII never leaves the machine.
- [`stablecoin-policy`](https://github.com/lcosent/experiments-public/tree/main/stablecoin-policy) — Selective-disclosure policy engine for stablecoin payments. Per-role views, predicate attestations, declarative policy language.
- [`machine-payments`](https://github.com/lcosent/experiments-public/tree/main/machine-payments) — Agent-to-agent payments with strict budgets, escrow and signed receipts across card and crypto rails.

**Decisions and evals**

- [`agent-debate`](https://github.com/lcosent/experiments-public/tree/main/agent-debate) — Advocate, skeptic and judge agents pressure-test a consequential decision: hiring, product, policy, M&A.
- [`fin-evals`](https://github.com/lcosent/experiments-public/tree/main/fin-evals) — Eval harness for LLMs on financial reasoning. Four narrow tasks, scored deterministically.
- [`prompt-eval-arena`](https://github.com/lcosent/experiments-public/tree/main/prompt-eval-arena) — A/B harness for prompt iteration: deterministic and LLM-as-judge scoring, paired Wilcoxon, effect sizes.

**Frontier science, for curiosity**

- [`clinvar-classify`](https://github.com/lcosent/experiments-public/tree/main/clinvar-classify) — LLM-assisted clinical variant classification with retrieval bundles.
- [`bio-bench`](https://github.com/lcosent/experiments-public/tree/main/bio-bench) — Eval harness for LLMs on biological reasoning. Five task families, 80 examples.
- [`arxiv-radar`](https://github.com/lcosent/experiments-public/tree/main/arxiv-radar) — Weekly arXiv digest of emerging and receding research themes.
