### What's here

**Evals & frontier AI**

- [`fin-evals`](https://github.com/lcosent/fin-evals) — Domain eval harness for LLMs on financial reasoning. Four narrow tasks scored deterministically — no LLM-as-judge.
- [`bio-bench`](https://github.com/lcosent/bio-bench) — Narrow eval harness for LLMs on biological reasoning. Five task families, 80 examples.
- [`prompt-eval-arena`](https://github.com/lcosent/prompt-eval-arena) — Rigorous A/B harness for prompt iteration. Paired Wilcoxon, effect sizes, replicate-run variance.
- [`arxiv-radar`](https://github.com/lcosent/arxiv-radar) — Weekly frontier digest for arXiv. Surfaces emerging vs receding research themes.

**Applied AI**

- [`clinvar-classify`](https://github.com/lcosent/clinvar-classify) — Research probe: LLM-assisted clinical variant classification with retrieval bundles. 60 ClinVar variants, no training.
- [`kyc-validator`](https://github.com/lcosent/kyc-validator) — Local-only KYC document validator. LLM extraction + sanctions screening, all on-device. PII never leaves the machine.
- [`agent-debate`](https://github.com/lcosent/agent-debate) — Multi-agent bull/bear/judge debate for pressure-testing investment theses.

**Tools real users would buy tomorrow**

- [`family-tax-scenarios`](https://github.com/lcosent/family-tax-scenarios) — International family life-event tax simulator. Inheritance, foreign gifts, cross-border marriage.
- [`rsu-tax-optimizer`](https://github.com/lcosent/rsu-tax-optimizer) — RSU vest simulator and sell-vs-hold optimizer for US tech workers.
- [`green-card-timing`](https://github.com/lcosent/green-card-timing) — Green card timing and path optimizer. Priority date projections, AC21, EB-1A self-assessment.
