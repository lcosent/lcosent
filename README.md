### What's here

**Evals & frontier AI**

- [`fin-evals`](https://github.com/lcosent/fin-evals) — Domain eval harness for LLMs on financial reasoning. Four narrow tasks scored deterministically.
- [`bio-bench`](https://github.com/lcosent/bio-bench) — Narrow eval harness for LLMs on biological reasoning. Five task families, 80 examples.
- [`prompt-eval-arena`](https://github.com/lcosent/prompt-eval-arena) — Rigorous A/B harness for prompt iteration. Both deterministic and LLM-as-judge scoring, paired Wilcoxon, effect sizes.
- [`arxiv-radar`](https://github.com/lcosent/arxiv-radar) — Weekly frontier digest for arXiv. Surfaces emerging vs receding research themes.

**Applied AI in regulated systems**

- [`clinvar-classify`](https://github.com/lcosent/clinvar-classify) — Research probe: LLM-assisted clinical variant classification with retrieval bundles. 60 ClinVar variants, no training.
- [`kyc-validator`](https://github.com/lcosent/kyc-validator) — Local-only KYC document validator. LLM extraction + sanctions screening, all on-device. PII never leaves the machine.
- [`stablecoin-policy`](https://github.com/lcosent/stablecoin-policy) — Selective-disclosure policy engine for stablecoin payments. Per-role views, predicate attestations, declarative policy language. TypeScript.
- [`agent-debate`](https://github.com/lcosent/agent-debate) — Multi-agent advocate/skeptic/judge debate for any consequential decision: hiring, product, policy, M&A.

**Tools real people could use**

- [`life-scenarios`](https://github.com/lcosent/life-scenarios) — Scenario engine for major life-event decisions. Career breaks, relocations, education funding, large transactions.
- [`rsu-tax-optimizer`](https://github.com/lcosent/rsu-tax-optimizer) — RSU vest simulator and sell-vs-hold optimizer for US tech workers.
